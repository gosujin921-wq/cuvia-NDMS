# CUVIA 재난안전관제시스템 데모

창원특례시를 대상으로 만드는 재난안전관제 데모. 시 전체 조망에서 시작해 지구·센서·CCTV로 좁히고,
경보 이력과 주민 전파를 거쳐 3D 침수 시뮬레이션까지 이어지는 흐름을 화면 다섯으로 보여준다.
화면 구성은 남해군 조기경보시스템 시연 자료를 기준으로 삼았다. 여기에 다섯 화면이 들고 있는 것을
한 번의 질문으로 모아 오는 AI 검색을 옆길로 붙였다.

| 화면 | 무엇 |
|---|---|
| SCR-01 | 종합상황 |
| SCR-02 | 재난관제 (구 SCR-03 상황대응을 흡수해 결번) |
| SCR-04 | 통계·분석 |
| SCR-05 | 디지털트윈 |
| SCR-06 | AI 검색 |

```bash
cd designs
corepack pnpm install
corepack pnpm dev      # http://localhost:5400
```

## 폴더

| 폴더 | 무엇 |
|---|---|
| [designs/](./designs/) | 앱. Vite + React + Tailwind v4 ([실행법](./designs/README.md)) |
| `docs/` | 작업 문서·참고자료·매뉴얼 |

> ⚠ **`docs/` 는 저장소에 실리지 않는다**(`.gitignore`). 인증키가 든 문서와 대용량 참고자료(84MB)가
> 있어서다. 새로 클론하면 이 폴더가 **없다.** 필요하면 별도로 받는다.
> 안에 무엇이 있는지는 아래 "문서" 절에 적어 둔다.

`designs/cctv-src/` 도 저장소에 없다(원본 PNG 40MB). 서빙본 `public/cctv/*.jpg` 는 실려 있고,
원본을 받으면 `node scripts/cctv-build.mjs` 로 다시 굽는다.

## 고치는 순서

**코드가 사양이다.** 화면 구성·수치·시나리오가 바뀌면 `designs/src` 를 고친다.

| 무엇 | 어디 |
|---|---|
| 확정값(원장 32건 · 발령 기준 · 침수영향 · SOP · 전파) | `src/demo/*.ts` |
| 화면 동작 | `src/pages/` · `src/components/` |
| 시연 중 변하는 상태 | `src/state/ScenarioProvider.tsx` |
| DS 진입점 | `src/ds.ts` 한 곳 |

작업 규율은 [CLAUDE.md](./CLAUDE.md) 가 든다.

## 추후 개발로 넘길 때

이 데모는 이관을 전제로 짰다. 무엇이 준비돼 있고 무엇을 손봐야 하는지는
`docs/고도화/코드-이관-준비.md` 에 감사 결과로 적어 뒀다. 요지만 옮기면:

- DS 는 `src/ds.ts` 한 경로로만 받는다. 제품으로 옮길 때 **이 파일의 재수출 대상만** 바꾼다
- 화면은 `demo/` 의 **원시 배열이 아니라 파생 함수**를 문다. 데이터 원본을 갈아도 시그니처만 지키면 화면이 안 바뀐다
- 남은 일 셋: 동기 함수를 비동기로 · `ScenarioProvider` 를 연출/업무/UI 셋으로 분리 · 시연 트랙 분기 걷어내기

배포가 갑자기 깨지면 그쪽부터 확인한다.
