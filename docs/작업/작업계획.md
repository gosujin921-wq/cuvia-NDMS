# 작업 계획

> 화면 구성은 [03 화면정의서](../정본/03_화면정의서.md), 메뉴·이동은 [02 IA 화면구조](../정본/02_IA_화면구조.md) 를 따르고,
> 이 문서는 "무엇을 어떤 순서로 만드는지"만 다룬다.

## 현재 상태

화면 다섯이 모두 돈다. 지구·장비·이벤트·기상·연계 수치는 [04 데모 데이터](../정본/04_데모_데이터.md) 에 확정됐다. `type-check` · `build` 통과.

시연 대본은 [05 시나리오](../정본/05_시나리오.md) 에 있고, 구현을 03 문서와 대조한 판정은 [감사](../감사/01_구현_대조_감사.md) 에 있다.

| 화면 | 상태 |
|---|---|
| SCR-01 대시보드 | 동작. 지도 · 지구 목록 · 기상 · 통계 도넛 · 연계 현황 · 색상 기준표 |
| SCR-02 조기경보 | 동작. 지구 확대 지도 · 장치/이벤트 핀 · 센서/CCTV 팝업 · 실시간 수치 · 월별 이벤트 · 풍향풍속 |
| SCR-03 이벤트·대응 | 동작. 이벤트 카드 목록 · 지도 · CCTV 4분할 · 발령 기준표 · 발생 그래프 · 전파 · 전파 내역. **위험도 판정 · SOP · 실행 결과는 미구현**(차수 I) |
| SCR-04 통계 | 동작. 지구·기간 조회 · 요약 4종 · 수위/강우 이중축 그래프 · CSV 다운로드 |
| SCR-05 디지털트윈 | 동작. 3D 씬 · 레이어 11종 · 침수 슬라이더 · 미니맵 · 지구 이벤트 · 날씨 |

화면 간 이동은 대시보드 → 조기경보 → 통계·디지털트윈으로 이어져 있다. 센서 팝업의 [상세 측정현황 보기]는 `/scr-04?device=` 로 그 장비의 지구를, [Twin 모드 실행]은 `/scr-05/:districtId` 로 그 지구의 3D 씬을 연다.

데모에 실제 CCTV 스트림이 없다. 영상 자리는 LIVE 표시로 두고 있고, 시연용 영상을 확보하면 바꿔 넣는다.

### 차수 J — 감사 미결 (기존)

새 대본이 **정면으로 지나가는 자리**로 성격이 바뀌었다. 이전에는 "시연 중 피해 가면 되는 것" 이었다.

| 순서 | 할 일 | 어디 | 왜 이제 필수인가 |
|---|---|---|---|
| J-1 | SCR-03 발생 그래프가 선택한 이벤트 구간을 그리게 (A-1) | `pages/scr-03/EventDispatchPage.tsx` · `demo/measurements.ts` | S8 이 해제된 주인공 사건을 연다 |
| J-2 | SCR-05 침수면이 지형 고도와 겨루는지 브라우저 확인 (D-1) | `lib/flood-scene.ts` | S4 가 "여기가 잠깁니다" 로 판단 근거를 만든다 |
| J-3 | SCR-04 봉우리 구간을 지구별 이벤트에서 잡기 (B-8) | `demo/measurements.ts` | S8 검증 장면이 띠·봉우리·예측선 셋을 겹쳐 읽는다 |
| J-4 | 봉암지구 CCTV 이름 중복 (B-9) · 나머지 (B-6·B-7) | 여유 있을 때 | 시연에 지장 없음 |

J-1 · J-2 · J-3 을 끝내면 [05 시나리오 §6](../정본/05_시나리오.md) 의 해당 제약을 지운다.

### 순서

I-1 이 먼저다. 시계가 서야 격상(I-2)이 서고, 격상이 서야 예측·판정(I-3·I-4)이 붙을 자리가 생긴다.
그다음 I-4 → I-5 → I-6 이 SCR-03 한 화면 안에서 이어지고, I-7 · I-8 · I-9 는 독립이라 병행할 수 있다.
J 차수는 I 와 무관하게 아무 때나 끼워 넣는다.

**감사 재실시가 필요하다.** [감사 문서](../감사/01_구현_대조_감사.md) 는 2026-08-12 정본 기준이고, 그 뒤 정본 01~05 가 모두 바뀌었다. I 차수를 끝낸 뒤 다시 대조한다.

### 문서 밖 준비물

- **시연용 CCTV 영상.** 데모에 실제 스트림이 없다. 서항지구 2대 · 봉암지구 3대가 먼저 필요하다.
  확보 전까지 영상 자리는 LIVE 표시로 두고, 시연에서는 "이 자리에 현장 영상이 붙는다" 로 말한다
- **시연 녹화본.** 대본대로 한 번 녹화해 두면 현장 네트워크·지도 타일 사정과 무관해진다

## 공통 원칙

- 부품은 DS(`@cuvia/components`) 우선, 없으면 이 앱 안에 신규. DS 저장소 수정 금지
- 목록형 화면은 DataTable + StatusDotLabel + PaginationBar 패턴
- 날짜·시각은 `src/lib/datetime.ts`, 최소 폰트 13px, 배경에 opacity 색 토큰 금지
- 지도 위 마커·팝업은 패널·버튼보다 아래 레이어
- API 규격·보관 정책 등 백엔드 결정 영역은 03 문서 §6 에 항목만 남기고 화면에서 지어내지 않는다
