# 작업 계획

> 화면 구성은 [03 화면정의서](../레거시/정본/03_화면정의서.md), 메뉴·이동은 [02 IA 화면구조](../레거시/정본/02_IA_화면구조.md) 를 따르고,
> 이 문서는 "무엇을 어떤 순서로 만드는지"만 다룬다.

## 현재 상태 (2026-08-13)

화면 여섯이 **개편 정본(01~05)대로 서 있다.** 차수 I(시나리오 척추 17항목) · J(감사 미결 4항목)를 마쳤고,
그 위에 시연 대본 자동 주행(`designs/scripts/walkthrough.mjs` — S0~S9 · 12프레임)으로 시각 대조까지 끝냈다.
시각 대조에서 나온 6건은 당일 수정 — 기록은 [감사 2회차](../감사/01_구현_대조_감사.md). `type-check` · `build` 통과.
대외 검수(v3 대조) 지적 6건을 반영한 고도화 차수 K(K-1~K-7)와, [상황대응 화면 통합안](상황대응_화면_통합안.md)을 반영한
차수 L(L-1~L-5)도 당일 완료했다(2026-08-13) — 기록은 [감사 3회차](../감사/02_고도화_감사.md).
대외 검수 2차 지적(SCR-02 가 사건 하나로 묶이지 않는다)을 반영한 차수 M(M-1~M-7, 재난관제 사건
중심 재구성)도 당일 완료했다.

감사 잔여도 없다 — 마지막 남았던 B-7(이벤트 표식 핀 모양)은 레이어 표식을 지도 문법으로
통일하면서 함께 닫았다(장비 원형 · 이벤트 채움 타일 · 위험요소 띠·점선·면, `LayerSwatch`).

데모에 실제 CCTV 스트림이 없다. 영상 자리는 전부 `designs/public/cctv` 의 **실촬 스틸**이 받고
라벨은 LIVE 다. 어느 컷을 트는지는 `cctvStillAt(device, now)` 하나가 정한다 — 화각은 지구 유형에서
나오고(해일 → 항만 · 내수 → 도시 · 하천/저수지 → 저수지), 대본 카메라 넷은 컷을 명시한다.
그 지구 사건이 경보에 닿으면 대본 카메라만 위험 컷으로 갈린다(04 §2-5). 스트림이 열리면
`CctvStill` 한 부품만 바꿔 넣는다.

I-1(상태 엔진 + 시계)이 먼저다. 시계가 서야 격상(I-2)이 서고, 격상이 서야 시나리오·판정(I-3·I-4)이 붙을 자리가 생긴다.
그다음 I-4 → I-5 → I-6 이 SCR-03 한 화면 안에서 이어진다. I-7~I-16 은 서로 독립이라 병행할 수 있고,
그중 I-10(화면명)·I-14(라벨)는 기계적이라 아무 때나 먼저 쳐도 된다. J 차수는 I 와 무관하게 아무 때나 끼워 넣는다.

**감사 재실시는 끝났다.** [감사 2회차](../감사/01_구현_대조_감사.md)(2026-08-13)가 개편 정본 기준으로
스모크 12종 + 시각 대조 12프레임을 마쳤다 — 어긋남 0 · 잔여 B-7 하나.
