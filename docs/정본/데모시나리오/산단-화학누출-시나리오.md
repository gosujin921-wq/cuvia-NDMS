# 창원산단 화학물질 누출 — 정리 이전

> 서항 해일(8/12) · 봉암 침수(8/13) 에 이어지는 **3편**. 무대는 창원국가산업단지. 날짜 `2026-08-14 (금)` 아침. 폭염 3일째다.
> **결말: 주민 인명 피해 0 · 실내대피 3,800명 · 학교 하교 보류 1,240명. 다만 우리가 사건을 알기 7분 전에 사업장 안에서 이미 3명이 실려 나갔다.**
> 이 문서는 현재 5개 화면 구조에 맞춘 **성립 후보 시나리오**다. 수치·근거가 확정돼 `04_데모_데이터.md`에 등재되기 전에는 구현 명세로 쓰지 않는다.
> `?` 표시는 채워야 할 자리. **(신설)** 은 `04_데모_데이터.md` 또는 화면에 없어서 등재해야 하는 값.

## 이 편이 왜 필요한가

1·2편은 **자연재난**이다. 재난 분야 4개(풍수해 · 기상·기후 · 수자원 · 산지·지반)가 전부 자연재난이고, 원장 18건도 물 14 · 강우 3 · 지반 1로 전부 자연재난이다. 그런데 재난안전법상 재난은 **자연재난 + 사회재난**이고, 시 상황실은 둘 다 받는다. 담당자가 1·2편만 보면 "여긴 물만 보네" 로 읽힌다.

**그래서 3편은 재난의 성격 자체를 바꾼다.**

| | 1·2편 (자연재난) | 3편 (사회재난) |
|---|---|---|
| 사건이 시작되는 순서 | 징후가 먼저 온다 → 우리가 본다 → 일어난다 | **이미 일어났다** → 우리가 뒤늦게 안다 |
| 우리가 막는 것 | 사건 자체의 피해 | **번지는 것** |
| 사고 현장의 주인 | 없음 (자연) | **사업주** — 시가 명령할 수 없다 |
| 미래를 아는 근거 | 조위표(서항) · 없음(봉암) | **풍향 전환 예보** |

이 한 줄이 3편의 주제다.

> 자연재난은 오는 것을 보고 대비한다. **사회재난은 이미 일어난 뒤에 알게 된다.** 시가 할 수 있는 일은 번지는 것을 막는 일이다.

## 사건의 뼈대

창원은 **계획도시**다. 창원대로를 축으로 남쪽이 공업지역, 북쪽이 주거지역으로 갈려 있다. 이 편은 그 축을 넘는 이야기다.

```
       [ 북 · 정병산 · 비음산 ]

   ─── 주거지 · 학교 · 어린이집 ────────  ← 바람이 돌면 여기
   ═══════════ 창 원 대 로 ═══════════
   ─── 창원국가산업단지 · 누출 지점 ────  ← 지금 여기
                                     ↘  아침 북동풍
       [ 남 · 불모산 ]  ← 지금은 이쪽 (사람이 희박하다)

   서쪽 마산만 · 남쪽 진해만  →  낮에 해풍이 들어온다
```

1. **08:12** 산단 도금 사업장 배기설비 이상 → 불화수소 누출 시작. 근로자 3명 이송. **시 상황실은 아직 모른다**
2. **08:19** 산단 대기측정소 농도 임계 초과 → 시스템 이벤트 `화학물질 누출 **주의보**`
3. 이때 풍향은 **북동 3.1 m/s**. 확산이 불모산 사면 쪽으로 밀린다 — 지금은 사람이 없는 방향
4. **08:46 경보 격상.** 농도가 계속 오른다. 그래도 방향은 여전히 안전하다
5. **09:05** 기상청 예보 갱신. **해풍 전환이 11:10 → 10:40 으로 당겨진다**
6. 전환하면 남서풍 4.8 m/s. 확산 방향이 **180도 돌아** 창원대로를 넘는다 → 주거지 도달 **11:32 예상**
7. **09:41** 담당자가 전환 **전에** 대응등급 `실내대피` 승인
8. **11:05** 실제 전환 (예보보다 25분 늦음) → **11:58** 실제 주거지 도달 (예보보다 26분 늦음)

**농도는 오르는데 방향이 안전하다. 그 안심을 예보 한 줄이 깬다.**

## 아직 못 채운 것

- `?` **화학물질 발령 기준 3단계의 실제 근거.** 농도 임계는 PAC/AEGL 같은 공표 기준이 있는 영역이라 임의 숫자를 박으면 1·2편의 발령 기준표(04 §3)와 격이 안 맞는다. 확인 전까지 화면에는 **단계 이름만** 쓰고 숫자를 비운다
- `?` **물질명.** 표면처리업에서 실제로 쓰는 물질이어야 하지만 특정 사업장이 연상되면 안 된다. 물질을 특정하지 않고 `특정대기유해물질` 로만 쓰는 대안도 있다
- `?` **사업장·시설 명칭.** 실명은 쓰지 않는다. `창원산단 3구역` 의 구역 번호도 실제 단지 구획과 맞는지 확인 필요
- `?` **취약시설 실명·개수.** 개수만 쓰고 실명은 쓰지 않는다. 위치는 시연용 근사값 (04 §1 좌표와 같은 기준)
- `?` **영향 인구 3,800명의 근거.** 입자가 어디로 가는지는 바람장이 말해 주지만 그 안에 몇 명이 사는지는 우리가 모른다. 04에 등재하지 못하면 S4에서 인구 숫자를 빼고 **범위와 취약시설 유무만** 보인다
- `?` **`실내대피` 를 대응등급 축에 세울 수 있나.** 못 세우면 대응등급은 `경보` 로 두고 조치 종류를 별도 표기하는 대안. 04에서 먼저 정한다
- **풍향 격자 해상도는 문제가 아니다.** `wind-field.json` 은 0.25도(약 25km) 격자라 시 안에서 방향이 거의 균일하다. 입자를 화면 전체에 뿌리면 그게 흠이지만(그래서 지금 코드 주석이 "도 규모로" 라고 적혀 있다), **점에서 뿜으면 균일한 것이 오히려 맞다** — 실제로 수 km 안에서 바람은 대체로 한 방향이다. 다시 구울 필요는 없다
- `?` **아침 프레임.** 지금 `wind-field.json` 은 12~23시 12프레임이다(태풍 솔릭 2018-08-23 · 04 §5 남동 7.2 m/s 에 맞춘 날). 이 편은 08~14시가 필요하고 **풍향이 도는 날**이어야 한다. `scripts/fetch-wind-field.mjs` 로 해풍 전환이 뚜렷한 여름 하루를 다시 골라 굽는다 — 기존 서항 편 프레임을 덮지 않도록 **파일을 따로 둔다**

## 이 편을 접기로 하면

★★★ 세 개(분야 추가 · 시설 축 · 실내대피 등급)가 부담이라고 판단되면, **S3·S4 만 살리는 축소판**이 가능하다.

풍향 전환으로 판단이 급해지는 컷(S3)과 분지에 공기가 갇히는 트윈(S4)은 **자연재난인 폭염·미세먼지로도 성립한다.** 폭염은 이미 04 §5에 있고 분야를 새로 만들 필요가 없다. 다만 그렇게 하면 "자연재난에만 국한됐다"는 처음의 문제는 그대로 남는다.

**분류체계를 건드리지 않고 사회재난을 넣는 방법은 없다.** 이 편의 비용은 대부분 거기서 나온다.
