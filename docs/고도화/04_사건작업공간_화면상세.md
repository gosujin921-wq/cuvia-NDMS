# CUVIA Phase 2 사건 작업공간 화면 상세

> 상태: 화면 방향 기준안. 대표 도시침수 데모의 화면 배치와 상호작용을 설명하며, 픽셀 치수·문안·수치·운영 SOP를 확정하지 않는다.
>
> 기준일: 2026-09-14
>
> 적용 범위: 기존 `/scr-02/:districtId`를 중심으로 `/scr-01`, `/scr-05/:districtId`, `/scr-04`, `/scr-07`과 연결한다. 새 라우트를 정의하지 않는다.

## 1. 이 문서가 답하는 질문

사건 후보를 연 담당자가 **어떤 이벤트가 같은 사건에 속하는지 확인하고, 현재 위험과 미래 영향을 판단한 뒤, 대응과 결과로 이어가는 화면**을 어떻게 구성할 것인가?

사건·이벤트의 의미와 상태는 `01_이벤트·사건모델.md`, D0~D8의 순서는 `02_대표데모시나리오.md`, 메뉴·화면 역할과 기존 라우트는 IA 문서가 소유한다. 이 문서는 그중 사건 작업공간의 정보 배치와 화면 행동만 구체화한다.

## 2. 화면의 기본 구조

사건 작업공간은 특정 현장 하나의 팝업이 아니다. 사건 범위가 지점·시설·구역·지구·도시 전역으로 달라져도 같은 판단 흐름을 유지한다.

```text
종합상황 SCR-01 → 사건 선택 → SCR-02 사건 작업공간
                                  중심: 사건 범위와 현재·예상 영향을 표시하는 지도
                                  좌측: 관측과 관련 이벤트 현황
                                  우측: 위험 판단·전망·대응 결과 요약과 다음 행동
                                  하단: 선택 사건의 CCTV·현장영상
                                  대응 실행: 사건 맥락을 유지하는 집중 팝업
                                  ↘ 전망 상세: 같은 지도가 예측 화면으로 바뀜(IA-03). 화면 이동 없음
                                  ↘ 기록·보고서: 기존 SCR-04·07
```

좌우 패널의 폭, 접힘 방식과 카드 높이는 디자인 단계에서 조정한다. 한 번에 모든 정보를 펼치기보다 현재 판단에 필요한 정보를 우선 보여준다.

| 영역 | 먼저 보여줄 내용 | 선택했을 때 |
|---|---|---|
| 사건 머리 | 제목·범위·처리상태·갱신시각, 판단이 있으면 위험등급 | 현재 선택한 알림 또는 사건 맥락 확인 |
| 중심 지도 | 실제·예상 영향 범위, 센서·CCTV·시설·조치 대상 | 선택 이벤트의 위치와 영향 강조 |
| 좌측 관측 | 주요 센서·시설의 현재값·추이·품질 | 선택 주체의 그래프와 파생 판정 확인 |
| 좌측 관련 이벤트 | 선택 알림·사건에 연결된 이벤트를 시간순으로 | 위치·영상·근거 상세로 이동 |
| 우측 판단 | 위험도 매트릭스 등급·주요 기여 근거, 4축 설명, 반대 근거·불확실성 | 근거를 다시 선택해 확인 |
| 우측 전망 | 유효시각·예상 영향과 기준/대안 요약 | 같은 지도가 예측 화면으로 바뀌어 기준·대안 비교 |
| 우측 대응 요약 | SOP 권고·승인 상태·실행 결과 요약과 다음 행동 | 집중 팝업에서 대응 실행 |
| 현장영상 | 사건 관련 카메라와 VLM 장면 | 큰 영상과 분석 문장 교차확인 |
| 대응 실행 팝업 | 사건 요약·SOP·승인·전파·조치·결과 | 실행 국면의 단일 조작면 |

## 3. 사건 범위와 관련 이벤트

| 범위 | 지도에서 중심이 되는 것 | 판단·대응의 관점 |
|---|---|---|
| 지점·시설 | 특정 도로·센서·CCTV·펌프장과 주변 영향 | 실제 위험 확인과 현장·시설 조치 |
| 구역·지구 | 배수권역·행정동·하천 구간과 영향 면 | 같은 원인의 복합 징후와 구간별 우선순위 |
| 도시 전역 | 광역 특보·예측과 여러 영향 지역 | 지역·기관별 우선순위와 연관 사건 |

같은 지구에 있다는 이유만으로 모든 이벤트를 사건 근거에 넣지 않는다. 선택한 복합 알림을 열었으면 그 알림을 구성한 이벤트, 사건을 열었으면 사건에 연결된 이벤트를 기본 목록에 보여준다. 현재 사건과 연결되지 않은 지구 내 이벤트는 별도 구분해 볼 수 있다. 광역 상황에서 독립적인 담당·조치·종료 조건을 갖는 지역·시설은 연관 사건으로 분리한다.

관련 이벤트 한 줄은 **무엇·언제·어디서·왜 연결됐는지**가 먼저 읽혀야 한다. 수위·강우·특보·영상·시설·예측·품질을 사용자에게 이해되는 종류로 구분하고, 원천·파생·분석 같은 내부 계층명은 기본 태그로 노출하지 않는다. 지연·결측·의심과 추가 확인 필요 여부는 해당 근거에서 확인할 수 있게 한다.

이벤트를 선택하면 지도 위치와 관측 상세가 함께 바뀐다. CCTV/VLM을 선택하면 실제 영상과 분석 결과를 나란히 확인한다. 예측 갱신 이벤트를 선택하면 연결된 Forecast의 기준시각·유효시각·영향을 확인하고, 같은 지도가 그 시각의 디지털트윈 화면으로 바뀐다(IA §8). 별도 화면으로 이동하지 않는다.

## 4. 판단·전망·대응의 관계

우측 패널의 판단은 위험도 매트릭스의 **결과와 근거**를 설명하는 자리다. 위험등급·지표별 주요 기여·완화·반대 근거·불확실성을 보여준다. 심각도·긴급도·확실성·추세 4축은 별도의 최종등급이 아니라 판단을 이해하는 설명이다. 판단 전에는 확정된 등급처럼 보이지 않게 한다.

전망은 현재 관측과 구분한다. 기준 전망, 사용할 수 있는 대안 전망, 유효시각과 영향 대상, 모델·버전·가정·한계를 보여준다. 유효한 전망이 없거나 대안을 계산할 수 없으면 임의의 침수면이나 결과로 대체하지 않는다. 예측 화면과 현재 상태를 오갈 때 선택 사건·전망·유효시각·대안 맥락을 유지한다. 기존 `/scr-05` 경로는 IA §5.2대로 남기되 사전 조건분석·훈련 실행(IA-T01)이 쓴다.

대응은 권고 확인, SOP 항목 검토, 담당자 승인, 전파·시설 요청, 실행 결과 확인으로 이어진다. **판단·전망은 지도 위 우측 패널, 대응 승인·실행은 별도의 집중 팝업**으로 분리한다. 우측 패널에는 대응 진입과 진행·결과 요약만 남긴다. 실행 조작이 지도·패널·팝업에 중복되지 않게 팝업이 열린 동안 활성 조작면은 하나다. 닫으면 결과가 우측 요약과 사건 이력에 이어진다.

집중 팝업에서는 사건·판단 요약, SOP 항목, 승인·전파·시설 요청과 결과를 같은 흐름으로 검토한다. 전파문 최종 확인이나 대체조치처럼 별도 확인이 필요한 행위만 그 안의 확인창으로 처리한다. 긴급 대응도 같은 팝업으로 진입한다. 광역 사건의 지역·기관·시설별 조치는 이 대응 맥락 안에서 확장한다. 팝업의 정확한 크기·탭 수·영상 배치는 화면 검토에서 정한다.

집중 팝업의 SOP는 우선순위(MUST·SHOULD·MAY)와 실행방식(자동·수동) 두 축으로 읽히고, `상황실 관제 · 담당기관 · 주민 전파 · 현장 조치` 네 단계의 대응 흐름, 진행률, 항목 줄로 구성한다. 주민 전파(CAP)는 한 항목이며 채널별 결과가 그 아래 붙는다. 이 구조는 CSMS SOP 대응 탭을 따르기로 했다(2026-09-14 결정). 항목별 우선순위 부여 기준과 문안은 운영 SOP 확인 뒤 확정한다.

긴급 상황에서는 유효한 디지털트윈 전망을 기다리느라 대응 검토가 막히지 않아야 한다. 사용한 근거와 전망 부재를 구분해 보여주고, 사건 확인 및 승인 경계는 유지한다. 내부 감시·근거 보존 같은 조치와 외부 전파·시설 요청은 실행 시점을 구분한다. 자동 항목이라도 대외 전파·시설 요청은 승인 없이 실행하지 않는다.

## 5. 대표 데모에서 확인할 화면 흐름

1. SCR-01의 침수 복합 알림 또는 후보에서 해당 지구와 사건을 선택한다.
2. SCR-02가 사건 범위로 열리고 좌측에 관련 이벤트가 나타난다. 같은 지구의 무관한 이벤트는 분리된다.
3. 수위·VLM 이벤트를 선택해 지도 위치, 관측값, 영상과 연결 이유를 확인한다.
4. 우측에서 위험도 매트릭스 결과와 반대 근거·불확실성을 확인한다.
5. Forecast 이벤트를 눌러 같은 지도의 예측 화면에서 기준·대안 전망과 예상 영향을 비교하고 [이 전망으로 대응 검토]로 넘어간다.
6. 사건 맥락을 유지한 집중 팝업에서 대응안을 검토하고 승인·실행한다.
7. 결과가 사건 이력·우측 대응 요약에 반영되고 SCR-04·07의 기록·보고서로 이어진다.

## 6. 이번 단계에서 확정하지 않는 것

- 패널의 픽셀 폭, 탭·접힘 방식, 3D 전환 연출과 모바일 배치
- 위험도 점수·가중치·시각·인원·기관명·SOP 문안의 데모 예시값을 운영 기준으로 채택하는 일
- 참조 제품의 팝업 크기·탭 수·영상 배치를 CUVIA 요구사항으로 그대로 복사하는 일
- SOP 항목별 우선순위 부여 기준과 문안을 운영 기준으로 채택하는 일
- 광역 대응 상세의 탭·목록 형태와 역할별 권한·승인 단계

위 항목은 실제 화면 검토와 관계 기관의 운영 기준 확인 후 결정한다. 이 문서는 화면의 **역할, 정보 우선순위, 선택과 전환의 관계**를 기준으로 삼는다.
