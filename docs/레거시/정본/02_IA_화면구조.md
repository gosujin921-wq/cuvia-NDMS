# 02 IA 화면구조

## 1. 메뉴

그룹 없이 5개 단층이다. 메뉴 순서는 **평시 업무 순서**다 — 전체를 보고, 지구로 좁혀 확인하고 대응하고, 되짚고, 앞을 본다. AI 검색은 그 어느 칸에도 속하지 않아 맨 뒤에 둔다.

메뉴명은 기능명이 아니라 **역할명**이다(참고자료 §1-1). 화면마다 답하는 질문이 하나씩 있다 — 종합상황 "창원 전체에서 어디가 위험한가", 재난관제 "무슨 일이 발생했고 왜 위험하며, 어떻게 대응할 것인가", 통계·분석 "무엇이 반복됐고, 사건은 어떻게 끝났는가", 디지털트윈 "언제까지 어디까지, 누구에게 영향이 가는가", AI 검색 "흩어진 근거를 자연어로 어떻게 연결하는가".

재난관제의 질문만 겹이 있다. 화면(지도·센서·격상)이 "무슨 일이 발생했고 왜 위험한가"에 답하고, 그 위의 **대응 실행 집중 팝업**(03 §2)이 "어떻게 대응할 것인가"에 답한다. 확인과 대응을 화면 둘로 가르지 않는다 — 경보가 뜬 화면에서 바로 대응까지 가는 것이 관제사의 흐름이고, 확인은 이 메뉴 대응은 저 메뉴는 시스템 사정이지 업무 사정이 아니다(차수 N · 구 SCR-03 통합).

| 순서 | 화면 ID | 메뉴명 | 경로 | 아이콘 | 전면 |
|---|---|---|---|---|---|
| 1 | SCR-01 | 종합상황 | `/scr-01` | `mdi:view-dashboard-outline` | O |
| 2 | SCR-02 | 재난관제 | `/scr-02` | `mdi:map-marker-radius-outline` | O |
| 3 | SCR-04 | 통계·분석 | `/scr-04` | `mdi:chart-line` | |
| 4 | SCR-05 | 디지털트윈 | `/scr-05` | `mdi:cube-scan` | O |
| 5 | SCR-06 | AI 검색 | `/scr-06` | `mdi:creation-outline` | |

**SCR-06 은 순서가 아니라 옆길이다.** 나머지 넷은 담당자가 순서대로 밟는 칸이고, AI 검색은 어느 칸에 서 있든 말로 물어 답을 받는 자리다. 그래서 메뉴 맨 뒤에 두되 진입은 SCR-01 종합상황 하단 중앙의 자연어 질의 바가 맡는다(03 §1). 사이드바 항목은 시연 중 눌릴 자리가 아니라 "이 화면이 있다"를 보이는 자리다.

**재난 기준 진입은 이번 범위 밖이다.** 분류 축(04 §4-0)이 서면 "풍수해 → 폭풍해일 → 영향지역" 으로 들어가는 두 번째 진입 UX 도 가능해지지만, 이번 데모의 강점은 창원 전체 → 서항지구가 빠르게 읽히는 것이다. 재난 분야·유형은 필터·통계·데이터 구조까지만 쓰고, 재난 중심 진입은 확장 사항으로 남긴다(03 §7).

**메뉴 순서와 시연 순서는 다르다.** [05 시나리오](./05_시나리오.md) 는 사건 한 건의 시간 순서를 따르므로 재난관제에서 디지털트윈(SCR-05)으로 나갔다가 **재난관제로 돌아와** 대응을 실행한다. 영향 분석은 대응을 결정하기 전에 봐야 결정을 바꿀 수 있기 때문이다. 메뉴는 평시 순서, 시연은 사건 순서 — 둘을 맞추려고 메뉴를 뒤집지 않는다. 평시에 트윈을 먼저 여는 담당자는 없다.

전면(fullBleed) 화면은 상단바 없이 본문이 화면 전체를 쓴다. 지도나 3D 가 배경인 화면이고, 나머지 화면 요소는 그 위에 오버레이로 얹는다.

코드: `designs/src/layout/nav.ts`, `designs/src/router.tsx`. 진입 경로 `/` 는 곧바로 SCR-01 로 보내고 별도 진입 화면을 두지 않는다.

## 2. 화면 간 이동

화면 안에 다음 화면으로 가는 길이 있다. **[05 시나리오](./05_시나리오.md) 는 사이드바를 한 번도 누르지 않고 이 길만으로 끝까지 간다.** 메뉴로 다니면 다섯 화면이 따로 노는 것처럼 보이고, 화면 안의 길로 다니면 사건 하나를 처리하려고 이어져 있는 것으로 보인다. 데모에서 끊기면 안 되는 연결이다.

```
SCR-01 종합상황
  │ 지구 목록·지도 라벨 클릭         → SCR-02 (해당 지구로 확대)
  │ 자연어 질의 바 · 질의 칩         → SCR-06 (그 질의의 답)
  │
SCR-06 AI 검색
  │ 답변 카드의 [바로가기]           → SCR-02 / SCR-04 / SCR-05 (근거가 있는 화면)
  │
SCR-02 재난관제
  │ 판단·대응 레일 [대응 실행] → 같은 화면 집중 팝업 (판정 요약 · SOP · 실행)
  │ 센서 팝업 [이 사건 대응하기]     → 같은 화면 집중 팝업 (진행 중일 때만)
  │ [디지털트윈 분석]               → SCR-05 (해당 지구 3D · 시점 유지)
  │ 센서 팝업 [상세 측정현황 보기]   → SCR-04 (해당 지구 기간 조회)
  │
SCR-05 디지털트윈  (사건 연계 분석)
  │ [분석 결과를 사건에 반영]        → SCR-02 (그 사건이 선택된 채 복귀 · 조건·영향·근거가 사건에 붙는다)
  │ [대응 판단으로 돌아가기]         → SCR-02 (반영 없이 복귀)
  │ 참고(접힘) 과거 이벤트 클릭      → SCR-02 (같은 곳)
  │ 미니맵 지구 클릭                → 같은 화면, 다른 지구
SCR-05 디지털트윈  (사전 모의분석)
  │ [모의분석 결과 저장]             → 이동 없음. 모의분석안으로만 남고 사건 이력에 닿지 않는다
  │ 지구·재난유형 셀렉트             → 같은 화면, 다른 대상
```

**시연이 도는 길은 이 한 줄이다.** 재난관제가 홈베이스다 — 트윈으로 나갔다가 돌아와 집중 팝업에서 실행한다.

```
SCR-01 → SCR-02 → SCR-05 → SCR-02 (집중 팝업) → SCR-04 → (에필로그) SCR-06
```

**SCR-06 은 이 줄의 끝에 에필로그로 붙는다**(05 §3 S9). 사건 여덟 장면에 질의 화면을 끼우면 시간이 끊기므로 본편에는 넣지 않고, 사건이 끝난 뒤 종합상황으로 돌아와 질의 바에서 연다 — 방금 처리한 사건을 말로 복기하는 20~30초다.

선택한 지구는 화면을 옮겨도 유지한다. SCR-02 에서 고른 지구가 SCR-05 에서 그대로 열려야 "이 지구를 3D 로 본다"가 성립하고, SCR-05 에서 검토한 결과가 SCR-02 복귀 시 그 사건에 붙어 있어야 "이 근거로 대응한다"가 성립한다.

**트윈은 사건에 종속된 화면이 아니다.** 진행 중 사건이 있으면 사건 연계 분석이고, 없으면 사전 모의분석이다(03 §5). 평소에는 예방·훈련 도구이고 사건이 나면 대응 판단을 보조한다. 모드는 사용자가 고르지 않고 사건 유무에서 파생되며, 모의분석 결과는 사건 id 를 들지 않아 대응 등급·타임라인·전파 원장 어디에도 닿지 않는다. 훈련으로 만든 숫자가 실제 사건 이력에 섞이면 SCR-04 집계와 사후 분석이 통째로 오염된다.

**[분석 결과를 사건에 반영]은 팝업을 대신 열어주지 않는다.** 트윈에서 돌아오면 판단·대응 레일이 강조된 판단 국면으로 서고, 집중 팝업은 담당자가 [대응 실행]으로 연다(03 §2). 판단은 지도·CCTV 와 함께 보는 레일에서, 실행은 팝업에서 — 국면 전환의 주도권은 화면이 아니라 담당자가 갖는다. 미니맵은 SCR-01 로 나가지 않고 같은 화면의 다른 지구로 옮겨 간다(03 §5).

## 3. 공통 골격

```
┌──────────┬───────────────────────────────┐
│          │ 상단바: 화면명 · 화면 ID        │
│ 사이드바  ├───────────────────────────────┤
│  (5메뉴)  │           본문 영역             │
└──────────┴───────────────────────────────┘
```

- 사이드바: 80px 접힘 ↔ 240px 펼침. 접힘 상태에서도 아이콘 아래 라벨을 보여 아이콘만 눌러 오가는 시연 조작이 가능하다
- 브랜드 영역 클릭 → SCR-01
- 다크 테마 고정. 24×365 상황실 환경 기준
- 전면 화면은 상단바를 쓰지 않는다

코드: `designs/src/layout/`.

## 4. 화면 번호

번호는 **메뉴 순서(평시 업무 순서)** 와 같은 방향이되, 한 번 부여한 번호는 바꾸지 않는다. 화면을 추가할 때는 이 문서를 먼저 고치고, `nav.ts` · `router.tsx` · `pages/scr-NN/` · [03 화면정의서](./03_화면정의서.md) 를 같은 번호로 맞춘다.

**SCR-03 은 결번이다.** 상황대응 화면은 차수 N 에서 SCR-02 재난관제로 통합됐다(03 §2 · §3). 번호를 재사용하면 옛 문서·감사 기록의 SCR-03 참조가 다른 화면을 가리키게 되므로 비워 둔다.
