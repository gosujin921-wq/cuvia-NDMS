# 대표 데모 데이터 구성 전략

> 상태: 1차 공식 대조 작업메모 - 정본 흡수 전·구현 기준 사용 금지
>
> 작성: 2026-09-10. 정본이 아니라 시연 데이터 방향을 정하기 위한 작업 문서.
>
> 물음: 02 §5.1 이벤트 중 어느 것을 실제 API·원본 파일·승인 표본으로 구성하고, 어느 것을 합성 데이터로
> 보완해야 하는가.
> 근거 후보: `docs/외부-API-인계.md`(Phase 1 외부 연계), `designs/src/lib/*` · `designs/scripts/*.mjs`(현재 구현), `designs/public/weather/*.json`(구운 자료).
>
> 검토 메모: 현재 구현은 Phase 1 현황 자료일 뿐 Phase 2 원칙이 아니다. 아래 API 제공 여부·사용 조건·
> 과거 시각 정렬은 공식 자료와 실제 응답으로 확인해야 한다. 합성 데이터는 대표 데모를 완성하기 위한
> 허용 수단이지만 `dataOrigin=합성 데이터`, `ingestionMode=모의`와 사건 기준시각을 명시해야 한다.
> 특히 지형에 임의 수위를 입힌 화면은 검증된 침수예측이나 `CUVIA 계산`으로 표현할 수 없다.

실제 API·원본·표본을 우선 활용하되, 데모 시점에 확보하지 못한 창원시 계측·시설 데이터는 합성 데이터로
구성한다. 이후 원본을 받으면 동일 이벤트 계약을 유지한 채 교체한다.

## 4. 날짜를 하나로 맞춘다

Phase 1은 자료마다 날짜가 다르다(바람 2018-08-23 태풍 솔릭, 기온 2025-08-24 폭염, 강수 2024-09-21 호우, 수온 2025년). 대표 사건은 기준시각을 하나 고정한다. 다른 날짜·지역의 원본을 사건 맥락에 맞게 변환하면 원본 재생이 아니라 `합성 데이터·모의`로 표시한다.

후보는 **2024-09-20~21**이다. 완료보고 p.60이 이 날 창원 주의보→경보, 알람 526건(관로 290 · 도로 83 · 우수받이 102)을 기록했고, 강수 격자가 이미 이 날짜로 구워져 있다. 특보(E2)와 조위(E3)를 신청해 받을 때도 같은 날짜로 받는다.

## 5. 지금 할 수 있는 것과 신청할 것

- **지금:** E1 강수 격자를 시연 시각에 맞춰 다시 굽기. 바람 · 기온을 같은 날짜로 굽기. 하천범람지도 붙이기.
- **신청 후보:** 기상청 API허브 특보 인증을 준비한다. 조위는 중단된 바다누리 API를 신청하지 않고 공공데이터포털 공지의 신규 국가중점데이터 대체서비스를 먼저 식별한다.
- **합성 필요 후보:** 관로·도로수위, 펌프·저류시설, 현장 결과는 데모 시점에 창원시 원본을 받지 못하면 합성 데이터로 구성한다. 02 §12 P0 공간·장비 매핑 확인 뒤 실제 데이터로 교체한다.
