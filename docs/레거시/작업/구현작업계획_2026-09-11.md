## I1 · D0~D8 최소 동선 (IA-01 → IA-05)

한 줄기가 처음부터 끝까지 돌게 한다. 각 화면은 여기 적힌 것까지만 만들고 나머지는 I2·I3에서 얹는다.

| 화면 | 경로 | 바꿈 | 추가 | 유지 |
|---|---|---|---|---|
| 종합상황 (SCR-01) | `/incidents` | 지구 목록·사건군 카드 → 사건 우선 큐. CCTV 스트립 → 감시 우선 카메라. 기관 연계 → 데이터 상태. 도넛·기상 카드 제거 | 큐 행에 최초 징후·"40분 뒤 침수 예상". 행을 누르면 사건으로 | 상단 스트립, 지도 이름표·레이어 |
| 사건 작업공간 (SCR-02) | `/incidents/:incidentId` | 캡슐 → 사건 헤더(처리상태 8종·4축). 교차검증 → 근거 목록(예측 줄에 [디지털트윈 보기]). 팝업 이벤트 정보 탭 → 사건 개요. 영향 패널 "검토 완료" 삭제 | [확인] [추가 확인] [오탐]. 계측 행에 연결된 이유·수신 시각. 타임라인 미래 눈금 | 계측 추이, 지도 마커·레이어, 팝업 3탭, 격상 동시 갱신 |
| 디지털트윈 (사건 지도 모드) | `/incidents/:incidentId/twin` | 트윈 페이지 3D 씬을 사건 지도 위로. 예측 줄 클릭으로 열린다. 수면 → 권역 침수심과 영향 표시. 영향 2열 축을 기준 대 대안으로 | 대안 선택(그대로/도로 통제/배수 대응). [이 전망으로 대응 검토]. [사건 보기] 닫기와 브라우저 뒤로가기로 `/incidents/:incidentId` 복귀 | 시간 조절, 원장의 미래를 눈금에 안 세우는 규칙 |

종료해서 기록으로 넘어가고, 훈련 시나리오 생성까지 요청할 수 있다. 화면 이동 중 사건 맥락이 유지된다.

## 정본 우선순위 결정 (2026-09-11 확정)

README §7 6단계 4번은 C 모의 예측·G 파생·A 훈련 목록·D·F 카드를 "일정이 허용하면"으로 두고, IA §18 핵심
목록은 C 모의 예측 화면과 G 파생 관계를 필수로 적고 있다.

결정(2026-09-11): C 모의 예측과 G 파생 장면은 제품 방향에는 포함하되 I4 선택 범위로 둔다. IA §18의
필수 목록에서도 선택 확장으로 옮기고 README §7의 구현 순서를 I0~I4로 정리한다. A 훈련 목록·실행과
D·F 카드도 같은 선택 범위다. D8의 TrainingScenario 생성 진입점과 전달 계약은 필수이며 C 훈련은 이번
범위가 아니다.

## 시연 대본은 화면 뒤

I1이 서면 D0~D8을 시각 순서로 엮은 대본을 쓴다. 대본은 시연자가 누르는 순서와 멘트를 든다. 어느 값이
시나리오 데이터인지는 제품 화면이 아니라 영업 설명·발표자 노트·기술 부록에서 밝힌다.
