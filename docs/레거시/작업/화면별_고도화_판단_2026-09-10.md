# 화면별 고도화 후보와 기획성 판단

> 상태: 검토 작업메모 - 정본 인용 금지. 채택분을 IA §17에 반영한 뒤 제거한다
>
> 작성: 2026-09-10. Phase 1 화면(`designs/src/pages`)에 지금 있는 것과 Phase 2 문서가 각 업무 공간에
> 요구하는 것을 대조해, 차이 나는 것만 추가 후보로 뽑고 하나씩 기획성을 판단했다.
>
> 대조 근거: IA §5~§12 · §17 · §18, 02 D0~D8 "보여줄 것" · §11 차별점 표, README §8.2 결정, 01 §12.1 확정 원칙.
> Phase 1 현황은 코드 인벤토리(2026-09-10 22시) 기준이다.

## 1. 판단 기준

채택은 다음 셋 중 하나 이상에 해당해야 한다.

1. 그 화면의 핵심 질문(IA §5)이나 D 단계의 결정·상태 전환(02)에 직접 닿는다.
2. 02 §11 차별점 7개 중 하나를 드러낸다.
3. Phase 1 자산(카드·탭·목록·패널) 위에서 재편이나 필드·행동 추가로 된다.

보류·기각은 다음 중 하나다.

- 면책성 표시(라벨·배지·"불가" 문구)
- 관리·편집 화면(운영 관리, 편집기)
- 데이터 근거 없이 정밀도를 만드는 것(구간·확률)
- 단일 사건 데모에서 쓰이지 않는 행동(병합·분리)
- 이미 같은 역할을 하는 부품이 있는 것

### IA-03 디지털트윈 (SCR-05. 사건 화면 안에서 열리고, 트윈 페이지는 모의훈련 실행 화면으로)

  헤더를 따르고 여기서 새로 정하지 않는다.
