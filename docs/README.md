# CUVIA 안전재난관제 데모 · 문서 안내

**기준은 코드(`designs/src`)다.** 화면 구성·수치·시나리오가 바뀌면 코드를 고친다. 이 폴더의 문서는 그 코드를 만들기 위한 작업 기록과 배경 자료다.

| 폴더 | 성격 | 언제 고치나 |
|---|---|---|
| [작업/](./작업/) | 무엇을 어떤 순서로 만드는지 | 작업을 시작·완료할 때 |
| [감사/](./감사/) | 구현을 대조한 판정 | 대조할 때마다 새 번호로 쌓는다. 지난 판정은 고치지 않는다 |
| [레거시/정본/](./레거시/정본/) | 코드 이전의 사양 문서 | 고치지 않는다 |
| [참고자료/](./참고자료/) | 원본 근거 | 고치지 않는다 |

발표(대외 산출물)는 산출물이 나올 때 폴더를 만든다.

## 감사
