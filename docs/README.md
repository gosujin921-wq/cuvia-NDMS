| 폴더 | 성격 | 언제 고치나 |
|---|---|---|
| [정본/](./정본/) | 화면·데이터·시나리오의 기준 | 만들 것이 바뀔 때. 코드보다 먼저 |

| 문서 | 무엇 |

| [02 IA 화면구조](./정본/02_IA_화면구조.md) | 메뉴·화면 목록·화면 간 이동 (코드: `src/layout/nav.ts`, `src/router.tsx`) |
